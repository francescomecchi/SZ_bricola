Genera il token Shopify per Bricola

Questa pagina resta nel browser: non richiede accesso al server di Gruppo Sinergia. Alla fine Shopify mostra il token da copiare e inviare.

1. Crea e installa l'app

  1. Apri il Dev Dashboard Shopify.
  2. Crea una nuova app con Start from Dev Dashboard.
  3. Nella versione dell'app imposta gli scope: read_orders,write_orders,read_products,write_products,read_inventory,write_inventory,read_locations,read_fulfillments,write_fulfillments
  4. Come App URL usa https://shopify.dev/apps/default-app-home.
  5. Come Redirect URL metti l'indirizzo HTTPS di questa stessa pagina (vedi campo sotto).
  6. Rilascia la versione e installa l'app sullo store Bricola.
  7. Da Settings copia Client ID e Client secret.

Autorizzazione ricevuta. Clicca il pulsante per far comparire il token nella pagina successiva.

2. Invia il token

Dopo il pulsante Shopify apre una pagina JSON. Copia il valore di access_token e invialo a Gruppo Sinergia insieme al dominio dello store.

Se Shopify risponde con un errore shop_not_permitted, l'app non e' stata creata nell'organizzazione dello store: ricrea l'app dal Dev Dashboard del merchant e reinstallala.
